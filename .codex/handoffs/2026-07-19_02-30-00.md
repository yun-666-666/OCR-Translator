# Live-path fixes and settings polish

## Task summary

Implemented the three high-confidence fixes in `docs/cleanup/branch-rereview-live-path-2026-07-19.md` and the requested settings UI polish:

1. Dialog formatting now preserves `!` before en/em dashes.
2. A completed translation cannot replace the overlay after a newer translation request has started.
3. OCR workers consume the immutable capture snapshot attached to each frame, avoiding live Tk/settings reads and keeping cache/recognition settings consistent with the captured frame.
4. The per-profile `Allow as translation failover` checkbox now shares the translated-text style row, saves immediately when toggled, and therefore survives an application restart.
5. The Custom AI short-log body warning is hidden from the regular settings view and exposed through a hoverable `!` directly after the checkbox.

## Important decisions

- Failover eligibility remains profile-scoped. The checkbox writes only `translation_failover_enabled` for the selected profile, so unsaved URL/model/key edits are not persisted as a side effect.
- The frame itself holds the capture snapshot. Queued frames therefore continue with the settings active at capture time even if the UI changes before the OCR worker dequeues them.
- Existing untracked cleanup documents, prior handoffs, release-artifact notes, and `.superpowers/` were preserved and were not staged.
