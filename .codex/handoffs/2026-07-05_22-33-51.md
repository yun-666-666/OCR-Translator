# Task summary

Fixed Custom AI reasoning-effort compatibility for xAI/Grok chat completions
models that reject the camelCase `reasoningEffort` capability with HTTP 400.
The fallback now recognizes xAI-style "does not support parameter
reasoningEffort" messages, retries once without reasoning effort, and remembers
the unsupported contract for the same profile/model/request kind/endpoint.
