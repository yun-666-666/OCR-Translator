## Important decisions made

- Updating an existing entry in a full translation cache no longer evicts an unrelated entry.
- Loading persisted cache data trims exactly to `max_size`.
- Runtime logs use process-local, thread-safe, line-buffered rotating writers. Debug logs retain three 5 MiB backups; Custom AI short logs retain two 2 MiB backups.
- Automated tests export a PID-specific temporary log directory, including to child Python processes, so tests cannot mutate the user's real logs.
- Adaptive OCR diagnostics log on state transitions or a 30-second heartbeat; scan interval behavior is unchanged.
- The Debugging page reads only the last 200 lines instead of loading the entire debug log.
- Debug-tail reads use the same writer lock as rotation, preventing Windows `WinError 32` sharing violations.
- The GUI clear-log action was not clicked because it is destructive and requires action-time confirmation. Its routing is covered by an automated test; visible validation used the non-destructive refresh action.
