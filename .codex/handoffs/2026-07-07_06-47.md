## Important Decisions

- Idle Start button uses `Primary.TButton` with the ink token background.
- Running Stop button uses `StartRunning.TButton` with amber `#d4700c`.
- `WHITE_CLEAN_PALETTE["window"]` is `#f0f2f4`.
- The pipeline pulse is bound to `app.is_running`.
- Stop and close paths cancel the pulse explicitly.
- UI language rebuild now also cancels the existing pulse before tearing down the old tab widgets, then restarts pulse on the newly built widgets when `is_running` is true.
- The mini-window visual tests remain useful as fast pixel checks, but full-app screenshots are the visual acceptance evidence.
