## Code review

- Independent review initially found two Important issues:
  - outline opacity did not follow text opacity;
  - new constructor parameters broke legacy positional calls.
- Both were reproduced with failing regression tests and fixed.
- Reviewer rechecked the current tree and reported no remaining Critical or
  Important findings, with a final verdict of ready to merge.

## Important decisions

- Used Qt's native glyph outline instead of CSS shadows or a widget-level blur.
- Outline width is clamped to 0-6 px; zero disables it.
- Existing saved text colors are not overwritten by config migration.
- The active ignored local config was explicitly changed to the requested
  yellow/black appearance.
- Outline alpha follows the existing text-opacity setting.
- New constructor parameters remain keyword-friendly while preserving every
  old positional parameter.
- The legacy tkinter fallback remains functional but cannot draw a glyph
  outline because `tk.Text` has no equivalent stroke API.
