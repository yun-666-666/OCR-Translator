## Important decisions

- Custom AI diagnostic bodies are opt-in and default to off; in-memory latency/cache metrics continue even when disk logging is disabled.
- Provider-controlled response bodies/messages are not part of the public error contract. Internal response classification remains private so cooldown/fallback behavior is preserved.
- Credentials are first written to unique staged references. Metadata/config is published only after all secure writes succeed; staged references are removed on write-before-raise, write-then-raise, metadata-save, and config-write failures.
- Log clearing atomically replaces the active path rather than truncating through it, preventing symlink/hardlink targets outside the log directory from being modified.
- Ignore-rule tests use real Git behavior instead of exact `.gitignore` text so equivalent safe refactors remain valid.
