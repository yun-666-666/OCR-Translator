# Streaming Translation Wrapper Buffer Handoff

## Task summary

Completed a fifth large translation-quality and streaming-UX optimization.

The final translation result was already normalized, but raw accumulated stream
partials could briefly display model wrappers. `CustomAIProvider.translate()`
now wraps the UI callback with a bounded partial-output filter that:

- withholds text only while it is still a possible known wrapper prefix;
- removes complete explanatory preambles;
- removes standalone translation labels after their newline is known;
- removes valid opening Markdown fences;
- withholds possible one-, two-, or three-backtick closing-fence suffixes;
- emits ordinary text as soon as it no longer matches a wrapper prefix;
- suppresses duplicate normalized partials.

Examples:

- ordinary `Hel` then `Hello` still emits both immediately;
- `Here is the translation:` fragments emit nothing until actual translation
  content arrives;
- `Translation:\nH` emits `H`;
- fenced `Hello` emits without opening or closing backticks;
- inline `Translation: unavailable` is preserved once the space proves it is
  content rather than a standalone wrapper;
- source-owned labels and fenced source text are preserved.

Chat Completions and Responses streaming use the same callback wrapper. Final
output continues through the complete normalization contract.

## Important decisions

- Used content-based bounded buffering rather than a timer, so no fixed delay is
  added to ordinary translations.
- Did not change the worker/UI coalescer; filtering happens at the provider
  boundary before raw partials reach it.
- Capped an unresolved fence-language header at 24 characters, preventing an
  unusual unmatched triple-backtick prefix from being buffered indefinitely.
- Preserved source-owned wrapper forms to avoid rewriting legitimate subtitle
  content.
- Renamed design/plan files from `prefix-filter` to `wrapper-buffer` because the
  repository's `*fix*.md` ignore pattern also matched the substring in `prefix`.
- `.codex/release-artifacts/` remains untouched and excluded.

## Remaining issues or next steps
