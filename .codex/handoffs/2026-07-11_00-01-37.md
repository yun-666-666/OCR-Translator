# Task summary

Reviewed the latest application log and the two newest handoffs, traced the
reported relay/model stall, and completed four major optimizations:

1. Reset translation scheduler state at stop/start boundaries so pending
   candidates and timers cannot leak into the next run. Advance the response
   sequence floor so old callbacks cannot display after restart, while
   preserving ownership/deduplication state for provider calls that remain
   active after the shutdown timeout.
2. Compress hot-path logging, coalesce repeated PaddleOCR/filter/display events,
   and remove OCR/translation bodies from the main debug log. Dedicated Custom
   AI short logs remain detailed. Added an AST-backed invariant preventing
   future direct interpolation of runtime subtitle text in main debug calls.
3. Make the primary Custom AI translation profile dropdown apply immediately,
   clear active context, invalidate prior cooldown/pending timers, and wake the
   newest subtitle while the app is running.
4. Make active-profile persistence single-shot and transactional at the
   in-memory boundary: failed saves restore the previous active profile and are
   reported through the existing GUI error boundary.
5. Add an explicit UI-only profile synchronization path so successful switches
   do not end the translation session twice and failed saves do not mutate
   translation-session lifecycle state.

# Important decisions

- Do not shorten a relay-provided 60-second cooldown blindly. The response may
  carry `Retry-After`; overriding it risks a retry storm. Instead, configuration
  changes now invalidate the old scheduler wait immediately and retry the latest
  subtitle with the newly selected immutable request snapshot.
- Preserve in-flight request identities when a provider call outlives the
  shutdown timeout. Clearing them would allow a duplicate request on restart
  and let the old worker cleanup erase ownership of newer work.
- Keep the dedicated Custom AI short log detailed for provider diagnosis, while
  making the high-volume main debug log content-free.
- Use a UI-only callback after the new profile helper; the helper already owns
  persistence, context reset, scheduler invalidation, and latest-subtitle wakeup.
- Do not loosen fuzzy subtitle deduplication: historical near-identical OCR
  inputs often produced meaningfully different translations.
