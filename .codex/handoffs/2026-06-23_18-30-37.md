## Subagent audit results

- PyInstaller/spec audit found that `GameChangingTranslator.spec` and `GameChangingTranslator_GPU.spec` currently list `tesserocr` only under `hiddenimports`; they do not explicitly bundle `tessdata` or native DLLs.
- Official-source audit confirmed:
  - PyInstaller frozen apps can use `sys.frozen` / `sys._MEIPASS`.
  - PyInstaller supports explicit data/binary collection in spec/hook files.
  - tesserocr should receive the concrete `tessdata` directory path for modern Tesseract.
  - Tesseract CLI and tesserocr API differ in how `TESSDATA_PREFIX`/path are interpreted; the app uses tesserocr API, so passing the actual `tessdata` directory is correct.
