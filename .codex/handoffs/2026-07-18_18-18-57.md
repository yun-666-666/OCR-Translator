## Important decisions

- `custom_ai_log_content_enabled` defaults to `False`; only an explicit UI opt-in writes full result text.
- Default records use `summarize_text_for_log`, which writes character and line counts rather than content.
- Prompt-cache and latency observations occur before the global debug-log gate, so disabling disk logging does not lose in-memory metrics.
- No cache key, transport, provider, profile, failover, or race behavior was changed.
