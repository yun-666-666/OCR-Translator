## Important decisions made

- Kept UI unchanged.
- Kept the source project `C:\Users\wordy\Desktop\OCR-Translator-3.9.6` untouched.
- Kept OCR scope limited to Custom AI OCR + tesserocr/Tesseract; no larger OCR engine was added.
- `OCRFrameCache` now has a `resize()` path that trims oldest entries when the cache is shrunk and clears everything when disabled.
- `ocr_frame_cache_size_var` is now wired to a live callback so the running cache follows the saved setting.
- Manual `clear_cache()` now clears OCR frame cache state and resets `last_processed_subtitle` so stale OCR cannot immediately repopulate the display.
