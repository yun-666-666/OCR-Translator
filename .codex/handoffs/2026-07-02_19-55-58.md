## Important decisions

- Kept cache behavior unchanged: eviction still removes the least-recently-used entries, and ties preserve insertion order through the enumerated index.
- Used `heapq.nsmallest` to select only the entries that must be evicted instead of sorting all access times.
- Added a regression test that patches module-level `sorted` to fail during eviction, so future changes do not accidentally reintroduce full-cache sorting.
