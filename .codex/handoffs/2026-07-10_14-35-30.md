# Runtime Log Coalescing

## Task summary

Completed the next major optimization in the ongoing audit: reduce repeated cache and translation-state debug lines without changing cache, queue, timer, translation, or runtime-metric behavior.

The pre-change 14:01-14:03 log window had 949 repetitive lines across four categories (483 cache misses, 361 pending queues, 80 duplicate in-flight skips, and 25 stale timers). A shared, thread-safe five-second coalescing gate now logs the first occurrence immediately, suppresses repetitions, and emits the current message plus the exact suppressed count at the next interval.

Only these four evidence-backed events opt in:

- unified translation-cache misses, keyed by provider/language route/model type;
- pending latest-translation queue state;
- duplicate in-flight translation skips;
- stale pending-translation timers.

High-frequency queue and duplicate messages no longer include source subtitle text. Cache hits/stores, provider requests, failures, display decisions, and all other logs remain unchanged.

## Live-session evidence

The 15:28-15:29 UI session exercised the implementation in the real application. Its coalesced lines represented:

- cache misses: 72 events in 2 emitted lines;
- pending queues: 58 events in 2 emitted lines;
- duplicate in-flight skips: 8 events in 2 emitted lines;
- stale timers: 10 events in 2 emitted lines.

Together, 148 real events produced 8 log lines, suppressing 140 repeated writes (about 94.6 percent) while retaining first occurrences and exact summary counts.

The same session also showed 24 successful xAI translation displays and no inactivity clear, confirming the previous subtitle-continuity increment in a normal UI run.

- 342 per-frame capture-latency lines;
- 44 OCR-routing lines;
- 44 PaddleOCR recognized-text lines;

That is 858 hot-path lines, now dwarfing the translated-state diagnostics. The next major optimization should preserve state transitions, slow/outlier timings, and periodic summaries while removing per-frame capture/OCR logging and repeated recognized source text.
