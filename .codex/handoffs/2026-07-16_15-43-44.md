# Subtitle bold, larger spinbox controls, and stop-aware failover handoff

## Task summary

Implemented the requested settings and UI changes, plus the highest-impact
additional optimization supported by the latest runtime logs:

- Added a persistent translated-subtitle bold option, defaulting to disabled
  for backward compatibility.
- Applied bold rendering consistently to PySide and Tk fallback overlays,
  including immediate live updates, color rerenders, resize rerenders, and old
  positional PySide calls.
- Enlarged every ttk spinbox arrow to 16 pixels and added `(5, 3)` padding.
  A real Tk probe reported a 33-pixel requested spinbox height.
- Stopped sequential Custom AI failover from starting another provider after
  `app.is_running` becomes false. The already-running HTTP request still exits
  through its existing bounded timeout.

## Important decisions

- `target_font_bold` defaults to `False`; no live
  `ocr_translator_config.ini` value was edited directly.
- PySide uses both `QFont.setBold()` and explicit HTML `font-weight`, so the
  effective font and HTML renderer agree.
- The new `font_bold` argument was appended after the old layout arguments to
  preserve existing positional calls.
- The stop optimization does not claim to forcibly cancel an HTTP request that
  is already blocking in another thread. It prevents the next sequential
  provider attempt immediately after the active request returns or fails.
- The pre-existing untracked
  `.codex/release-artifacts/release-notes-v3.10.3-2026-07-15.md` was not edited.
- No commit, push, merge, or release was performed.
