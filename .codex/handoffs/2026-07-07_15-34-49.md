## 关键发现

1. **PaddleOCR**：良好隔离，可作为长驻 subprocess，JSON over stdin/stdout
2. **截图热路径**：每 50–300ms 循环，帧哈希 MD5 → Rust 可换 blake3（5x 提速）
3. **翻译提供商**：均为 HTTP JSON API，`reqwest` 可完整替代
4. **SQLite 缓存**：schema v2，`rusqlite` 可直接复用现有文件
5. **Overlay**：PySide6 透明窗口 Phase 1 跳过，保留 Python
6. **配置**：60+ INI 字段 + normalize 函数，`serde` + `ini` crate 可迁移
