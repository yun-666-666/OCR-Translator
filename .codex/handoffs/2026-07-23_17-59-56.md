# Handoff — adaptive overflow-protection review fixes

## Task summary

Independently reviewed Grok's slow-route bounded-overflow protection and fixed two
correctness boundaries while retaining its intended scheduler behavior.

## Findings and fixes

1. The protection map is mutated from both the UI scheduler and translation-worker
   completion path.  It now uses one app-scoped re-entrant lock, including
   first-use initialization and session clearing.
2. The original key used only the endpoint host.  Slow state could therefore
   suppress a different endpoint path or wire API on the same host, profile, and
   model.  The key now uses a normalized endpoint path plus the wire API.
