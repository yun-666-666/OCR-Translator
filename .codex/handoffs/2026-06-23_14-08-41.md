# Setup entrypoint and root test discovery fix handoff

## Task summary

Fixed the two small issues found in the read-only review:

- Default `python -m unittest discover -v` failed because the root
  `test_custom_ai.py` looked for `handlers/translation_handler.py` one
  directory above the project.
- `setup.py` pointed the console script at the non-existent
  `ocr_translator.main` package and did not install the top-level runtime
  modules needed by `main.py`.
