# Handoff — stream transport bypass review fixes

## Task summary

Reviewed Grok's route-scoped temporary non-stream bypass and corrected three
behavioral boundaries while preserving the 2-failure / 30-second policy.

## Findings and fixes

1. A successful fallback for an empty/non-transport stream response retained an
   earlier transport-failure streak.  A later transport error could therefore
   enter bypass despite the failures not being consecutive.  The retry path now
   records whether its initial stream error was actually transport-class and
   only preserves the streak in that case.
2. `connect timeout` and `connection timed out` were classified as transport by
   the new bypass state but did not enter the existing same-request non-stream
   retry branch, so they could never contribute to the stated behavior.  They
   now use that retry branch and are counted.
3. The route-state map, per-route state, and metrics are accessed by concurrent
   translation workers.  The bypass now uses an app/provider-scoped re-entrant
   lock for atomic state transitions and metrics.
