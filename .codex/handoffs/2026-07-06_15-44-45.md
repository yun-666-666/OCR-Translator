# Task summary

Fixed the new PaddleOCR PP-OCRv6 backend failing during live CPU inference.

The latest app log showed the UI and worker were correctly routing to
`ocr_model = paddleocr`, but Paddle/PaddleX crashed inside the CPU oneDNN
path:

`ConvertPirAttribute2RuntimeAttribute not support [pir::ArrayAttribute<pir::DoubleAttribute>]`

After disabling MKL-DNN for CPU PaddleOCR initialization, live inference
reached result parsing and exposed a second wrapper bug with numpy `rec_boxes`.
Both issues are covered by regression tests now.
