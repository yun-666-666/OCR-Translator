# Task summary

Implemented focused validation for the OCR adaptive threshold `adaptive_block_size` setting so invalid values are normalized before they can reach OpenCV `cv2.adaptiveThreshold`.

# Files changed or created

- `ocr_utils.py`
  - Added `normalize_adaptive_block_size(value, default=41)`.
  - Added final block-size normalization inside `preprocess_for_ocr(..., mode='adaptive')`.
- `config_manager.py`
  - Normalizes `adaptive_block_size` during config load/update and writes corrected string values back to `ocr_translator_config.ini`.
  - Logs invalid normalization with the requested `Config: Invalid adaptive_block_size ... normalized ...` format.
- `app_logic.py`
  - Normalizes config value before creating `tk.IntVar`.
  - Normalizes OCR preview runtime reads before calling `preprocess_for_ocr`.
- `worker_threads.py`
  - Normalizes worker cache-key block-size reads.
  - Normalizes OCR runtime block-size reads before calling `preprocess_for_ocr`.
- `tests/test_adaptive_block_size.py`
  - Added tests for the normalization helper, config load write-back, worker runtime read normalization, and adaptive preprocessing fallback prevention.
