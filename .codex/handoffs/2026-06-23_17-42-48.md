- Kept UI unchanged.
- Kept the source project `C:\Users\wordy\Desktop\OCR-Translator-3.9.6` untouched.
- Kept OCR scope limited to Custom AI OCR + tesserocr/Tesseract; no larger OCR engine was added.

- Treated `tesseract.exe` not being on `PATH` as distinct from tesserocr API availability.
- Added Windows registry install directory discovery before hard-coded Program Files fallbacks, so the app now checks explicit config, `TESSDATA_PREFIX`, registry, Program Files, and LocalAppData style installs.
- Kept API OCR cache hits outside the concurrency gate. Cached repeated frames can now display immediately even when active provider calls are already at the configured limit.
