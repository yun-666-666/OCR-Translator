# Important decisions

- PaddleOCR is now the only local OCR backend exposed in runtime/UI/config; Custom AI OCR remains available through profiles.
- Removed Tesseract-only settings from defaults and settings save: path, confidence threshold, preprocessing mode, adaptive block/C values, and trailing-garbage cleanup.
- Removed native Tesseract/tesserocr engine code, tessdata discovery, language mapping, UI path browser, and packaging/dependency references.
- OCR preview is treated as PaddleOCR-only for local preview; Custom AI OCR remains API/profile based.
- Historical docs and old implementation plans were rewritten to avoid presenting Tesseract as an active supported path.
- `custom_prompt.txt` was aligned with `DEFAULT_CUSTOM_PROMPT` because the relevant Custom AI startup tests were failing on that mismatch.
