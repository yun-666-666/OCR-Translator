# Important decisions

- Metrics are stored in bounded deques with `max_events=240` and a 60 second
  default window; snapshot time trims stale timing entries.
- Worker/provider code records metrics only through duck-typed
  `app.runtime_metrics`; missing collectors or UI widgets are ignored.
- The Debug tab refreshes the diagnostics panel every 1000ms from `snapshot()`
  instead of repainting on each event.
- Race winner labels go through collector redaction before display or copy.
- Provider cooldown, active translation calls, concurrency limit, and OCR queue
  size are lightweight gauges, refreshed from existing in-memory state.
