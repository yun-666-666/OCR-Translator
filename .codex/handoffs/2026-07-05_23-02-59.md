# Task summary

Fixed overlay opacity instability that made source and target overlay windows
look briefly lighter while scrolling an underlying English web page.

# Files changed or created

- `ui_elements.py`
  - Removed the temporary `-alpha` decrease/restore from
    `ResizableMovableFrame.update_color()`.
  - Color refresh now updates widget backgrounds and calls `update_idletasks()`
    without changing window transparency.
- `pyside_overlay.py`
  - Cached PySide target overlay background/top-bar styles.
  - `update_color()` now skips reapplying unchanged background style, top-bar
    style, and text background state.
  - `show()` no longer reapplies the background style on every show.
- `overlay_manager.py`
  - Added a stable fallback target opacity of `0.4` for overlay creation paths
    without an app opacity variable.
- `config_manager.py`
  - Added default `target_opacity = 0.4` for new/migrated configs.
- `tests/test_overlay_startup.py`
  - Added regression coverage for Tk source overlay color updates not changing
    alpha.
  - Added source overlay creation coverage proving the creation-time color
    update does not add alpha jitter.
  - Added default target opacity coverage.
  - Added PySide style-cache coverage for unchanged background updates.
- `CHANGELOG.md`
  - Added version `3.9.7` release notes for the overlay opacity fix.
- `docs/CHANGELOG.md`
  - Added matching version `3.9.7` release notes.
- `.codex/handoffs/2026-07-05_23-02-59.md`
  - Added this handoff.

# Important decisions

- Kept the source overlay alpha stable instead of using alpha changes as a
  redraw workaround.
- Preserved the PySide target overlay transparency feature, but made the
  default target background opacity less transparent (`0.4`) to reduce visible
  bleed-through from scrolling page content.
- Avoided changing ordinary translation text updates or Custom AI/xAI reasoning
  fallback behavior.
- Did not touch or revert existing unrelated dirty workspace changes.
- GitHub push and release creation require the final commit hash, so they are
  performed after this handoff is staged with the fix.
