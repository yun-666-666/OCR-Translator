# Default custom prompt optimization handoff

## Task summary

Shortened and focused the default Custom AI translation prompt after reviewing the existing prompt assembly and current official OpenAI prompting guidance.

The approved default is now:

> Use context to resolve ambiguity. Translate naturally and concisely while preserving meaning, tone, and character voice. Keep names and game terms consistent.

The new prompt is 158 characters instead of 250, a reduction of 92 characters or 36.8%.

## Important decisions made

- Removed role, source/target language, line-break, and output-only instructions from the editable default because `custom_ai.py` already supplies them at the system level.
- Kept only the useful additional guidance: contextual ambiguity resolution, natural concise phrasing, meaning/tone/voice preservation, and terminology consistency.
- Updated both the runtime fallback constant and the shipped/current prompt file.
- Did not add automatic migration for arbitrary existing user prompts.
- Added exact-value tests in both startup test locations because root discovery and `tests` discovery use different modules.
- The shipped-file test strips only outer whitespace so a standard final newline does not create a false mismatch. Missing-file creation remains an exact content assertion.
- Did not change provider payload structure, context behavior, cache keys, language selection, rate limiting, or UI.
