## Important decisions

- `ApiOcrRequestSnapshot` intentionally exposes only safe diagnostic data. Raw provider configuration stays private and is copied only by `profile_copy()` for execution; it must not be logged.
- Endpoint cache identity contains a digest of credential-bearing endpoint scope rather than the endpoint secret material itself; visible diagnostics strip userinfo, query, and fragments.
- Session identity is `(generation, sequence)`. Capacity uses the all-generation executor registry, while the UI current-call set remains scoped to the active generation.
- Generation advances on reset/start, stop, cache clear, and shutdown. Workers remove their own exact token when they finish; callbacks check generation before every mutation path.
- A compatibility fallback invokes a guarded cache-hit callback synchronously only if an unusual legacy root object has no callable `after`. The normal Tk application always uses `after`.
