## Important decisions made

- Kept the fix in `CustomAIProvider`, where HTTP responses are decoded and parsed.
- Added `_load_response_json()` so non-streaming JSON is parsed from `response.content` as UTF-8 first, instead of trusting `response.json()` when a relay/server exposes the wrong charset.
- Added `_iter_utf8_response_lines()` and changed streaming chat/responses parsers to request raw bytes from `iter_lines(decode_unicode=False)` and decode them as UTF-8 in the provider.
- Applied the JSON helper to chat completions, Responses API, model-list parsing, and error payload parsing.
- Did not change prompts, UI rendering, profile settings, cache behavior, or the overlay.
