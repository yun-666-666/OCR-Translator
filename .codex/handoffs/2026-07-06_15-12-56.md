# Task summary

Added a selectable offline PaddleOCR backend for PaddleOCR 3.7 + PP-OCRv6
while keeping Tesseract and Custom AI OCR intact.

# Files changed or created

- `paddle_ocr_backend.py`
  - New lazy-loading PaddleOCR wrapper.
  - Tries installed `paddleocr` first, then the local `PaddleOCR-3.7.0`
    source directory.
  - Adds PP-OCRv6 tiny/small/medium model-name resolution, engine caching,
    optional 2x image upscale, confidence filtering, and result flattening.
- `config_manager.py`
  - Added PaddleOCR default settings.
  - Allows `ocr_model = paddleocr` during config normalization.
- `app_logic.py`
  - Initializes PaddleOCR settings variables.
  - Preserves PaddleOCR as a valid OCR model instead of migrating it to
    Tesseract.
  - Adds PaddleOCR engine-cache clearing on model/parameter changes.
  - Routes OCR Preview through PaddleOCR when the PaddleOCR backend is selected.
- `gui_builder.py`
  - Adds `PaddleOCR PP-OCRv6 (offline)` to the OCR model combobox.
  - Adds helper functions for OCR display options and selection resolution.
- `handlers/ui_interaction_handler.py`
  - Saves PaddleOCR settings.
  - Shows stability and OCR debug preview for local PaddleOCR while hiding
    Tesseract-specific path/preprocessing/confidence controls.
- `worker_threads.py`
  - Adds PaddleOCR settings/cache-key helpers.
  - Routes realtime local OCR to PaddleOCR when selected.
  - Uses PaddleOCR-specific cache keys.
  - Keeps Tesseract-specific trailing-garbage removal limited to Tesseract.
- `ocr_translator_config.example.ini`
  - Added PaddleOCR example settings.
- `tests/test_paddle_ocr_backend.py`
  - Added wrapper, config, UI helper, and worker routing tests.
- `docs/superpowers/plans/2026-07-06-paddleocr-ppocrv6-backend.md`
  - Added implementation plan.
- `.codex/handoffs/2026-07-06_15-12-56.md`
  - Added this handoff.

# Important decisions

- Kept Tesseract instead of deleting it, so it remains a fallback while
  PaddleOCR is validated on real subtitles.
- Used PP-OCRv6 `small` detection and recognition model names by default for a
  speed/accuracy balance suitable for subtitles.
- Did not route PaddleOCR images through Tesseract binary/adaptive preprocessing;
  PaddleOCR receives the source image with optional upscale.
- Kept stability threshold and OCR debug preview available for PaddleOCR because
  it is still a local OCR backend.
- Did not add visible PaddleOCR tuning controls yet; settings are present in
  config and app state to keep the UI change focused.
- Did not install PaddleOCR runtime dependencies into the Python environment.
