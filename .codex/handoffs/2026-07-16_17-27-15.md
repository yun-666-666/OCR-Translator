# Target Overlay Border Opacity Handoff

## Task summary

- Made the PySide target overlay border use the same opacity as the target
  background.
- When target background opacity is `0`, both the background and its rounded
  border are now fully transparent while translated text keeps its independent
  text-opacity setting.
- Kept the border instead of removing it so it remains useful at non-zero
  background opacity.
- The tkinter fallback required no change because it already applies opacity to
  the entire overlay window.

## Important decisions

- Chose opacity synchronization rather than deleting the border. This preserves
  the existing rounded visual boundary when the user wants a visible
  background, but removes the stray outline in fully transparent mode.
- Reused the existing `_hex_to_rgba()` conversion path, so background and
  border respond identically to every opacity value without introducing a
  second setting.
- Did not change text opacity behavior.
- Preserved the pre-existing untracked
  `.codex/release-artifacts/release-notes-v3.10.3-2026-07-15.md`.
