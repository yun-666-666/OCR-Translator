# Important decisions

- Kept `PySide6==6.7.3` and constrained Python support to 3.9-3.12 rather than upgrading Qt.
- Kept WebP as the default Custom AI OCR image format to preserve existing behavior; added explicit PNG/JPEG configuration instead of automatic provider fallback.
- Kept the legacy byte-returning `convert_to_webp_for_api()` path for compatibility and added metadata-aware OCR image payload handling alongside it.
- Treated `timeout_seconds` as an HTTP request timeout contract. Race loser cancellation remains a best-effort/result-discard boundary rather than forced socket cancellation.
- Did not bump the unified translation cache schema version; including `structured_output_contract` changes future Custom AI key hashes while old entries simply do not match the new parameterized key.
- Retained legacy provider documentation sections but reframed them as historical/reference paths so user-facing docs match the active Custom AI runtime.
