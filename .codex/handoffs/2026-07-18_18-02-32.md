## Problem

Commit `16812b9` introduced `translation_failover_enabled` and defaults non-active profiles to false for failover/race eligibility. The Custom AI profile editor had no control for this field, so ordinary multi-profile failover was unusable after migration.

## Changes

### `gui_settings_builder.py`
- Added `ai_profile_translation_failover_var` (`BooleanVar`, default `False`).
- `load_profile` loads `translation_failover_enabled` (missing/legacy → `False`) and clears to `False` for new profiles.
- Added one clearly labelled checkbox: "Allow as translation failover" in the existing AI Model Profiles frame (row 6).
- Save/add continue through the existing `build_profile_from_form()` path.

### `gui_profile_controls.py`
- `build_custom_ai_profile_values_from_form` always emits `translation_failover_enabled` (default `False`).
- When the checkbox var is present, its boolean value is passed through to add/update.

### `tests/test_custom_ai.py`
- Form-value tests for checkbox true/false, missing checkbox default, and settings-builder wiring.
- Profile manager persistence test covering default false, update true/false via form-value kwargs.

## O2 behavior preserved

- Active translation profile remains always eligible for failover/race.
- Other enabled profiles are eligible only when `translation_failover_enabled` is true.
- No runtime eligibility code changed in this correction.

## Out of scope / untouched

- Credentials, local config, runtime logs, timeout policy, Preview, OCR, unrelated UI.
- Rollback branch left intact.
- Unrelated untracked handoffs/docs/`.superpowers` not staged.

## Decisions

- Single checkbox in the existing profile editor; no new dialog/tab.
- Form-value path always includes the field with safe default `False` when the checkbox var is absent (test stubs / legacy form paths).
- Label English fallback: "Allow as translation failover" via `ai_profile_translation_failover_label`.

## Remaining issues

- Localized label key may need UI language strings if non-English packs do not fall back gracefully (English fallback is in place).
