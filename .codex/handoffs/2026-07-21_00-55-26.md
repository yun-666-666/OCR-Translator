| Surface | Role | Notes |

Hot / leak-adjacent sites addressed:

1. Graceful shutdown wait poll (was manual 1s timer; high frequency under load)
2. Models GET retry line (logged full `url`)
3. Transport error strings (api_key replace only; no auth/bearer/query redaction)
4. Metric labels (duplicate regex stack vs logger)

## Task summary

1. **`logger.sanitize_log_message`** — central redaction for auth headers, Bearer tokens,
   common `sk-`/`key-` secrets, query/header secret params, long opaque tokens, optional
   explicit `api_key`, optional max length.
2. **`logger.classify_log_error_class`** — stable classes:
   `rate_limit` / `auth` / `server_error` / `parse` / `transport` / `other`.
3. **`log_debug`** always runs messages through `sanitize_log_message` before disk write.
4. **`_LogCoalescingGate.prepare(..., status=)`** — status change forces emit inside the
   interval window and still reports suppressed_count.
5. **`log_debug_coalesced(..., status=)`** — optional status forwarded.
6. **`runtime_metrics.sanitize_metric_label`** — delegates to `sanitize_log_message`.
7. **`custom_ai_transport._sanitize_error`** — uses central sanitizer (TLS rewrite kept).
8. **Models GET retry** — no URL; logs `class=` + exception type only.
9. **Shutdown wait** — uses `log_debug_coalesced` with status `ocr:translation` and 1s
   interval (status transitions still visible).
10. **`app_logic`** re-exports `log_debug_coalesced` for facade callers.
