# Task summary

Completed big optimization #16: translation-context epoch invalidation.

Language, model, settings, and session changes clear Custom AI context. Provider
requests and cache lookups that started before that clear can no longer
repopulate the new session when they finish afterward.

Each clear increments a locked context generation. Translation/cache work
captures its starting generation, and context writeback is accepted only when
that generation remains current. The translation result itself is still
returned and can follow normal cache/log handling; only its obsolete context
side effect is suppressed.

  cache entry, usage log, or display-order processing.
