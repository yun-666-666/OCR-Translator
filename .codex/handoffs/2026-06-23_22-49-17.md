## Important decisions made

- Kept the optimization in the existing unified-cache path instead of introducing a separate new cache subsystem.
- Added optional disk persistence to `UnifiedTranslationCache` with a file path supplied by the app.
- Plumbed `custom_ai_translation_cache_file` from `app_logic.py` so the real app gets a stable cache location.
- Expanded the `custom_ai` cache key to include `custom_prompt`, `keep_linebreaks`, and `context`, preventing stale prompt/context hits from being reused.
- Kept error results out of the persistent cache.
- Did not add any UI toggle for this cache; it is a behavior-only optimization.
