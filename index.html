Real-time screen OCR translation

Game-Changing Translator

A Windows desktop app for translating text that cannot be copied directly. Select a screen region, run PaddleOCR or Custom AI OCR, translate through OpenAI-compatible Custom AI profiles, and display the result in a floating overlay.

Current Runtime Path

The active app is focused on PaddleOCR for local recognition and Custom AI profiles for translation and optional cloud OCR.

  • PaddleOCR is the supported local OCR backend.
  • Custom AI profiles target OpenAI-compatible endpoints.
  • Legacy local OCR runtime support has been removed.
  • Older provider modules remain only for compatibility and history.

Translation Workflow

The app keeps the capture, OCR, translation, cache, and overlay stages separate so each step can be tuned without changing the whole pipeline.

Local OCR Controls

PaddleOCR settings are exposed in the UI so users can balance speed and accuracy for subtitles, PDFs, games, and other screen content.

  • Language, OCR version, model size, and CPU/GPU device settings.
  • Minimum score and detection limit controls for noisy regions.
  • Preview support for checking whether the selected area is clean.

Custom AI Profiles

Custom AI profiles are the main way to connect translation and cloud OCR providers without hard-coding one vendor into the app.

  • OpenAI-compatible chat completion endpoints.
  • Per-profile model, key, URL, and prompt configuration.
  • Image payload options for Custom AI OCR: WebP, PNG, and JPEG.

Built For Long Sessions

The runtime includes queueing, stale-result handling, caching, and graceful shutdown so the overlay stays useful during repeated capture cycles.

  • Unified translation cache for repeated text.
  • Async OCR and translation worker threads.
  • Settings and overlay geometry saved on shutdown.

Common Uses

Use it anywhere text is visible but not selectable.

  • Games and visual novels with subtitle regions.
  • Videos, streams, screenshots, and image-heavy documents.
  • PDFs or apps that block normal copy and paste.

System Requirements

Windows 10 or Windows 11
Python 3.9-3.12 for source runs
No separate OCR engine install for bundled builds
API key required for online Custom AI translation

Quick Start

  • Launch the app and select the OCR source area.
  • Select the translation overlay area.
  • Choose PaddleOCR or configure a Custom AI OCR profile.
  • Configure a Custom AI translation profile.
  • Start translation and use the hotkey to pause or resume.
