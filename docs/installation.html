System Requirements

  • Windows 10 or newer (64-bit)
  • 4GB RAM minimum (8GB recommended)
  • For compiled version: 1-4GB free disk space (depending on version chosen)
  • For Python version: 500MB free disk space
  • Additional space for legacy MarianMT models if using offline translation (~500MB per language pair)
  • Internet connection (for Custom AI/OpenAI-compatible translation services and initial legacy MarianMT model downloads)

Installation Method 1: Compiled Version (Recommended for Most Users)

The compiled version provides the easiest installation experience with no need to install Python or dependencies. Simply download, extract, and run.

Choose Your Version

Game-Changing Translator is available in multiple versions to suit different needs and hardware configurations:

Version 3.9.5 - CPU-Only (~260MB) [Latest Version]

  • Best for: All users seeking the latest features with the Custom AI translation + Custom AI OCR workflow
  • Requirements: Any modern CPU
  • Download size: ~260MB compressed (1 file)
  • Note: Legacy MarianMT offline translation remains in the package for compatibility, but the current online workflow is centered on Custom AI profiles

Version 2 - Legacy Versions

Version 2 remains available for users who prefer the previous generation of the application:

Version 2 - GPU-Supported (~1.35GB)
  • Best for: Users with NVIDIA GPUs who want faster MarianMT translation performance
  • Requirements: NVIDIA GPU with CUDA support
  • Benefits: Significantly faster offline neural translation processing
  • Download size: ~1.35GB compressed (3 files)
Version 2 - CPU-Only (~188MB)
  • Best for: Users without dedicated GPUs or those prioritizing smaller download size
  • Requirements: Any modern CPU
  • Benefits: Smaller download, works on all systems
  • Download size: ~188MB compressed (2 files)

Installation Steps

  1. Download the required files for your chosen version:

    • For Version 3.9.5 (Latest): Download the file:
      • GameChangingTranslator_CPU-only_v3.9.5.exe
    • For Version 2 GPU: Download ALL 3 files:
      • GameChangingTranslator_GPU-enabled_v2.7z.001
      • GameChangingTranslator_GPU-enabled_v2.7z.002
      • GameChangingTranslator_GPU-enabled_v2.exe
    • For Version 2 CPU: Download BOTH files:
      • GameChangingTranslator_CPU-only_v2.7z.001
      • GameChangingTranslator_CPU-only_v2.exe

  2. Run the installer:

    • Double-click the .exe file you downloaded.
    • Choose your installation directory when prompted.
    • The installer will extract all necessary files automatically.

  3. Configure OCR:

    • Use the bundled PaddleOCR path, or configure a Custom AI OCR profile.
    • Select PaddleOCR for local OCR or Custom AI OCR for API-based recognition.
    • Leave the PaddleOCR source directory at the bundled default unless you use a custom checkout.
    • Set the PaddleOCR language, model size, and device fields in Settings.

  4. Run the application:

    • Navigate to the extracted folder.
    • Double-click GameChangingTranslator.exe.
    • The application will start immediately.

  5. First-time setup:

    • Verify the PaddleOCR settings in the Settings tab (should auto-detect).
    • Select source and target translation areas.
    • Configure your preferred translation method.
    • You're ready to translate!

What's Included

The compiled version includes everything you need:

  • GameChangingTranslator executable
  • All Python libraries and dependencies
  • Pre-configured settings
  • Documentation and user manual
  • Resource files for all supported languages

No Additional Setup Required

Unlike the Python version, the compiled version requires no separate OCR engine installation. All Python dependencies, translation libraries, and neural network frameworks are bundled and ready to use.

Installation Method 2: Python Source Version (For Developers)

This method is recommended for developers who want to modify the application or prefer running from source code.

Prerequisites

  • Python 3.9-3.12
  • Git (optional, for cloning the repository)

Step 1: Configure OCR

Game-Changing Translator supports local PaddleOCR and Custom AI OCR. Configure the OCR path you want to use:

  1. Use the bundled/local PaddleOCR source directory, or install the Python dependencies with pip install -r requirements.txt.

    • Select PaddleOCR for local OCR or Custom AI OCR for API-based recognition.
    • Set the PaddleOCR language, model size, and device fields in Settings.

  2. Keep the default PaddleOCR source directory unless you have a custom PaddleOCR checkout.

    • If you use a custom checkout, update the PaddleOCR source directory in Settings.

  3. Verify setup by launching the app and using the OCR Preview button while PaddleOCR is selected:

    python main.py

Step 2: Install Python and Dependencies

  1. If you don't have Python installed:

    • Download Python from python.org.
    • Make sure to check "Add Python to PATH" during installation.

  2. Clone or download this repository:

    git clone https://github.com/tomkam1702/OCR-Translator.git
cd OCR-Translator

  3. Install required Python packages:

    pip install -r requirements.txt

    This will install:

    • Core dependencies (numpy, opencv, paddleocr, Pillow, pyautogui)
    • Custom AI/OpenAI-compatible endpoint support through the Requests HTTP client
    • PySide6 RTL overlay support and keyboard hotkey support
    • Keyboard hotkey support

Step 3: Run the Application

  1. From the project directory, run:

    python main.py

  2. The application will start and display the main interface.

  3. If running for the first time, you'll need to:

    • Verify the PaddleOCR settings in the Settings tab
    • Select source and target translation areas
    • Configure your preferred translation method

Custom AI and Legacy Service Configuration (Both Installation Methods)

The current runtime path uses Custom AI profiles with OpenAI-compatible endpoints for online OCR and translation. Configure the base URL, API key, and model in the application's Custom AI profile settings. The Google, DeepL, and MarianMT notes below are legacy references for users who explicitly re-enable those paths in a fork.

Legacy Google Cloud Translation API (Optional):

  1. Create a Google Cloud account and project.
  2. Enable the Cloud Translation API.
  3. Create an API key:
    • Go to Google Cloud Console → APIs & Services → Credentials.
    • Click "Create credentials" → "API key".
  4. Copy your API key only if you are using a legacy Google Translate path.

Legacy DeepL API (Optional):

  1. Create a DeepL account at deepl.com/pro-api.
  2. Subscribe to a plan (including the free plan).
  3. Get your API key from the account dashboard.
  4. Copy your API key only if you are using a legacy DeepL path.

Legacy MarianMT (Offline Translation):

This legacy option requires no configuration as the models are downloaded automatically when first used. However, note that:

  • Models are ~500MB each.
  • First-time translation with a new language pair will take time to download the model.
  • A fast internet connection is recommended for the initial download.
  • GPU version processes translations significantly faster if you have a compatible NVIDIA GPU.

Troubleshooting

If you encounter issues during installation:

For Compiled Versions:

  • Application won't start: Ensure you have Visual C++ Redistributable installed.
  • PaddleOCR not found: Verify the path in Settings matches your installation location.
  • GPU version slow: Check if NVIDIA drivers are up to date and CUDA is working.
  • Antivirus warnings: Add the application folder to your antivirus exclusions.

For Python Source Version:

  • Python dependency errors: Make sure you're using Python 3.9-3.12 and try reinstalling dependencies.
  • Import errors: Verify all packages installed correctly with pip list.

Common Issues (All Versions):

  • Translation API errors: Check your Custom AI base URL, API key, model, and internet connection.
  • Legacy MarianMT errors: Ensure you have sufficient disk space and a stable internet connection for model download.
  • OCR not working: Verify PaddleOCR installation and path configuration.

For more help, see the Troubleshooting Guide.

Which Version Should I Choose?

Choose Version 3.9.5 - CPU-Only if:

  • You want the latest features and improvements.
  • You prefer Custom AI/OpenAI-compatible endpoints for online translation.
  • You need comprehensive API cost tracking and monitoring.
  • You want the smallest download size for a modern feature set.
  • You primarily use Custom AI profiles for online OCR and translation.
  • You don't mind leaving legacy MarianMT as a fallback/reference path rather than the primary translation method.

Choose Version 2 - GPU-Supported if:

  • You have an NVIDIA GPU with CUDA support.
  • You frequently use MarianMT offline translation as your primary method.
  • You want the absolute best performance for neural translation.
  • You don't mind the larger download size for maximum MarianMT performance.

Choose Version 2 - CPU-Only if:

  • You prefer the previous generation interface.
  • You don't have a dedicated GPU but want Version 2 features.
  • You primarily use API-based translation services but prefer Version 2.
  • You want maximum compatibility with Version 2 workflows.

Choose Python Source Version if:

  • You're a developer who wants to modify the application.
  • You prefer having full control over dependencies.
  • You want to contribute to the project.
  • You're comfortable with Python development environments.

For most users, Version 3.9.5 - CPU-Only provides the best balance of modern Custom AI features, translation quality, ease-of-use, and download size. Users who heavily rely on legacy MarianMT offline translation and have compatible NVIDIA hardware may prefer Version 2 - GPU-Supported for maximum offline performance.
