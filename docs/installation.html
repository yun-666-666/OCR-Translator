Installation Guide

This guide describes the current authoritative RapidOCR-enabled baseline. Later machine-specific local translation-model experiments are not part of the main project.

Supported runtime

  • RapidOCR is the default and recommended local OCR engine.
  • PaddleOCR is an optional advanced local engine with language/model, OCR version, size, device, score, upscale, detection and orientation controls.
  • Custom AI supports local or remote OpenAI-compatible OCR/translation endpoints through Chat Completions or Responses API.

Requirements

  • Windows 10 or Windows 11
  • Python 3.9 through 3.12 for source installations
  • A Custom AI endpoint for translation

Install from source

git clone https://github.com/yun-666-666/OCR-Translator.git
cd OCR-Translator
python -m pip install -r requirements.txt
python main.py

requirements.txt includes RapidOCR and the pinned PaddleOCR CPU stack. PaddleOCR is not preloaded at application startup; selecting it and starting OCR Preview or translation performs the first lazy initialization.

PaddleOCR GPU installation

The default dependency is CPU paddlepaddle. For CUDA acceleration, remove that CPU package and install the paddlepaddle-gpu build that exactly matches the machine's CUDA environment, following PaddlePaddle's official installation matrix. Keep the pinned paddleocr and paddlex versions from this repository.

Do not guess a PaddlePaddle GPU wheel. An incompatible CUDA build can prevent PaddleOCR from importing or can fail during model initialization.

First configuration

  1. Select the source capture area and translated overlay area.
  2. Keep RapidOCR selected for the fast default path. Select PaddleOCR only when its advanced controls are needed.
  3. Create a Custom AI translation profile with base URL and model.
  4. Choose Chat Completions or Responses API to match the endpoint.
  5. Enter an API Key for authenticated providers. Leave it blank for an unauthenticated local endpoint; the application then omits the Authorization header.
  6. Test the profile, then click Start.

Persistent files

The main INI configuration uses the application's stable configuration directory. Relative Custom AI profile paths, custom_prompt.txt, and the translation cache resolve from the application/project root, not the shell's current working directory.

Development tests

Install pytest only in a development environment, then run:

python -m pytest

pytest is not required for normal application startup or translation.
