## What Was Done

### modern_ui.py
- Added `WHITE_CLEAN_PALETTE` — flat white/ink/amber design token set replacing teal accents.
- `apply_white_clean_theme()` configures all ttk styles using the new palette (backgrounds, buttons, comboboxes, notebook tabs, scrollbars).
- Added 3-dot amber pipeline-pulse animation:
  - `_reset_pipeline_dots()` — sets all dots to idle surface-variant colour.
  - `_pulse_pipeline_step()` — self-cancelling per-tick step; stops on `is_running=False` or destroyed widgets.
  - `start_pipeline_pulse()` / `cancel_pipeline_pulse()` — public API with safe `after_cancel` + `_widget_exists_safe` guards.
- `_widget_exists_safe()` helper for all canvas checks.

### gui_builder.py
- `create_main_tab()` builds the 3-dot pipeline-dots row (Canvas widgets) stored in `app._pipeline_dot_canvases`.
- Settings tab now has an amber left-border accent strip (`settings_accent_bar`) via Canvas.
- Start/Stop button uses `StartIdle.TButton` / `StartRunning.TButton` styles.
- `_pipeline_pulse_palette` stored on `app` for pulse colour lookup.

### app_logic.py
- `__init__` calls `apply_white_clean_theme(self.root)`.
- Stop path (line 2145): `cancel_pipeline_pulse(self, dots, palette)`.
- On-closing path (line 2551): `cancel_pipeline_pulse(self, dots, palette)`.
- `update_ui_language()` restarts pulse with new canvases when `is_running=True`.

### tests/test_modern_ui.py
- 8 new unit tests added (total 14 pass):
  - `test_white_clean_palette_keys` — required palette keys present.
  - `test_apply_white_clean_theme_runs` — no exception on a bare Tk root.
  - `test_cancel_pipeline_pulse_noop` — safe when no timer exists.
  - `test_cancel_pipeline_pulse_cancels_id` — `after_cancel` called once.
  - `test_start_pipeline_pulse_no_op_when_not_running` — no timer scheduled.
  - `test_pulse_self_cancels_when_stopped` — `is_running=False` → pulse stops.
  - `test_pulse_self_cancels_on_missing_widget` — destroyed canvas → pulse stops.
  - `test_widget_exists_safe` — returns False for destroyed widget.

### tests/test_visual_phase2.py  *(new file)*
- 6 screenshot-based visual regression tests (all pass):
  - Window geometry 600×480.
  - Idle background = WHITE_CLEAN_PALETTE["window"] (`#f5f5f0`).
  - Idle pipeline dots = neutral (`surface_variant`).
  - Start button = ink on idle (`StartIdle.TButton`).
  - Running button pixel = amber (`#d4700c` family).
  - Settings tab accent bar = amber visible.
- Screenshots saved to `docs/screenshots/phase2/`.
